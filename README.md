# Assignment Management System

A full-stack Assignment Management System developed for the Sipna College Software Engineering Assessment.

## Level 1

B2 — Assignment Management System — Basic Submission Tracking

## Technology Stack

- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB
- Authentication: JWT
- API: REST

## Core Features

### Professor
- Create assignments
- View assignments
- Edit assignments
- Delete assignments

### Student
- View assignments
- View assignment details
- Submit assignments

### Automatic Submission Status
- Pending
- On Time
- Late
- Missing
